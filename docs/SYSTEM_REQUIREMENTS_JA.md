# Yamatana AI IME (MOZC Ver) 必要スペック

## 対応OS

- Windows 10 22H2（64ビット）
- Windows 11（64ビット）
- 日本語キーボードまたは日本語入力を利用できる環境

## 最低構成

- x64 CPU
- メモリ: 8 GB
- 空き容量: 3 GB以上（インストール後の使用量は約1.2 GB）
- 演算: CPUモード

## 推奨構成

- 4コア以上の比較的新しいx64 CPU
- メモリ: 16 GB以上
- GPUモードを使う場合: CUDA対応NVIDIA GPU（推奨）またはDirectX 12対応GPU、専用または共有メモリ4 GB以上
- CUDA実行時はCUDA 12系・cuDNN 9系ランタイムを使用（配布版に同梱）。

## 動作上の注意

- AIは既定でOFFです。OFF時は通常のMozc変換として動作し、AIモデルのCPU/GPUメモリを使用しません。
- 初めてAIをONにした時は、モデルの読み込みに数秒から数十秒かかる場合があります。
- CPUモードでは、Spaceキーなどによる明示変換時だけ最大2秒までAI候補の並べ替えを待ちます。通常入力中はAI推論を実行しません。
- AI変換にインターネット接続は必要ありません。
