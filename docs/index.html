WHY RERANKING

日本語入力に必要なのは、
文章を作るAIとは限りません。

Mozcの変換候補を活かしながら、文章に合う順番へ並べ直します。文章や未収録の単語をAIが自由生成する方式ではありません。

標準エンジンのDual-Encoderは文脈と候補を別々にベクトル化するため、文脈を候補ごとに繰り返し処理せず、候補側の計算結果も再利用できます。

GET STARTED · v2.1.1-beta

モデル同梱のMSIで、
新しいPCにもインストール。

Windows 10/11 x64向けの未署名ベータ版です。管理者権限と空き容量約3GBが必要です。フルMSIにはAIモデルが同梱され、旧バージョンのMSIや更新ZIPを別途ダウンロードする必要はありません。

フルMSI（Windows x64）をダウンロード →

SHA256SUMS.txtでファイルを検証してください。配布ファイル名の「Yamatana」は旧内部名です。既存インストール向け差分ZIP・旧セットアップZIPはこちら（差分ZIP単体では新規インストール不可）。

  1. 01
    フルMSIをダウンロード

    GitHub Releaseの Yamatana-AI-IME-MOZC-Ver-2.1.1-beta-x64.msi を取得します。

  2. 02
    SHA-256を確認して実行

    公開ハッシュと照合し、配布元を信頼できる場合に実行します。未署名のためWindowsの警告が出る場合があります。

  3. 03
    サインアウトまたは再起動

    インストール後にWindowsへ再サインインし、Win + SpaceでFumiori AI IMEを選びます。
