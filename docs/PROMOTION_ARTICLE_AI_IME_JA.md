# AIに変換候補を選ばせるIMEを作ってみた

## Mozcの変換候補をAIに選ばせるIMEを作ってみた

日本語入力の変換候補を、AIが文章の流れに合わせて選ぶIMEを作りました。

日本語入力でよくある困りごとは、ひらがなを漢字に変えられないことではありません。

変換はできても、文章の意味に合わない漢字が最初に出てくることです。

たとえば「はな」は、前の文章によって変わります。

```text
彼の顔のはな       → 鼻
庭には美しいはな   → 花
```

「けっさい」も同じです。

```text
役員が稟議書をけっさい       → 決裁
オンラインで代金をけっさい   → 決済
```

今回のデモでは、「あめ」の使い分けも確認できます。

```text
明日の天気予報はあめだ     → 雨
弟に御土産としてあめを買う → 飴
```

同じ読みでも、天気の話か、お土産の話かで正しい漢字は変わります。ここを文脈で選べることが、このIMEの見どころです。

YAMATANA AI IMEは、Mozcが作った変換候補を、入力中の文章に合う順番へ並べ直します。

Mozcの辞書や学習機能を使いながら、最後の「どの候補を先頭にするか」をAIが手伝う仕組みです。AIに文章を自由に作らせるのではなく、Mozcの候補の中から選ぶため、従来のIMEに近い安心感を保てます。

## 実際のMozcの候補を使って調べました

確認に使ったのは、あらかじめ人が用意した候補ではありません。実際のMozcに変換させて、Mozcが出した候補をそのまま調べました。

普段の入力に近づけるため、変換する単語の後ろに続く文章は使わず、すでに入力されている前の文章だけを使っています。

- 日常、仕事、IT、医療、製造、数字などの210例
- 1つの場面につき、単語だけの場合と、助詞や活用を含む場合を確認
- Mozcが出した候補のうち、上位5つをAIが比較
- 1回の変換は2秒以内

結果は次の通りでした。

|  | Mozcだけ | AIを加えた場合 |
|---|---:|---:|
| 自然な表記を含めた正解 | 152/210 (72.4%) | 208/210 (99.1%) |
| 誤って悪化した例 | — | 0例 |
| 2秒を超えた例 | — | 0例 |

ここでの「正解」は、`3時` と `三時` のように意味が同じ表記を含みます。一方、`鼻` と `花`、`決裁` と `決済` のように意味が変わるものは、別の答えとして数えています。

この結果は、実際のMozc候補を使った検証用の210例で得たものです。まだ大規模なユーザー入力ログによる結果ではないため、製品全体の精度が99.1%だと示すものではありません。検証条件を公開し、誰でも確認できるようにしています。

## 実際に改善できた例

### 日常の言葉

```text
彼の顔のはな             → 鼻
夕食前に食卓へはし       → 箸
贈り物を包む厚いかみ     → 紙
喉を潤す甘いあめ         → 飴
```

### 仕事やITで使う言葉

```text
出張後すぐ経費をせいさん         → 精算
公開前に記事をこうせい           → 校正
仕様変更に関する顧客のいこう     → 意向
深夜に発生したしょうがい         → 障害
```

### 数字や順位

```text
会議はさんじ                 → 3時
参加者はごにん               → 5人 / 五人
前回の成績はだいごい         → 第5位 / 第五位
```

数字なら何でも算用数字にするわけではありません。`一石二鳥` や `第三者` のように、漢数字のまま使う表現もあります。数字・日付・助数詞は、文章の意味を見ながら扱う必要があります。

## MozcとAIの役割を分けています

AIだけで日本語入力を作ると、自然な文章は作れても、IMEに必要な辞書や変換の細かな挙動を失うことがあります。

そこで、役割を分けています。

```text
Mozc      → 変換候補を作る
AI        → 文章に合う候補を選ぶ
安全機能  → 自信がないときはMozcの候補を変えない
```

AIが迷っているときは、無理に候補を変えません。新しい候補を出すことより、正しい変換を壊さないことを優先しています。

## まだ改善できるところ

調査を通して、次の課題も分かりました。

- `だい / ご / い` を別々に処理せず、`第五位` という一つの言葉として考える
- `じゅうごにち` を `15日` としてまとめる
- Mozcに候補がない `じゅうにこ → 12個` のような表現を、安全に補う
- メモ帳やブラウザなど、通常のWindows入力画面でも同じ結果になるか確認する

つまり、AIを大きくするだけでは不十分です。Mozcの候補、入力した文章、数字や専門用語のルールを組み合わせて、変換後に打ち直す回数を減らしていきます。
