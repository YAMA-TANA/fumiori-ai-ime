# 変換の一瞬に、トキメキを。

## Fumiori AI IME

### Mozcの安心感に、文脈を読むローカルAIを重ねる

同じ読みでも、文章の意味によって正しい漢字は変わります。

```text
彼の顔のはな             → 鼻
庭には美しいはな         → 花
役員が稟議書をけっさい   → 決裁
オンラインで代金をけっさい → 決済
月と地球の距離をはかる   → 測る
```

Fumiori AI IMEは、Mozcが作った候補を捨てずに、入力済みの文脈へ合う順番へ並べ替えます。AIが文章を生成するのではなく、利用者が確定する候補を選びやすくする製品です。

## 体験

1. いつも通りに日本語を入力する
2. Mozcが候補を作る
3. Dual-Encoder 70Mが文脈と候補を端末内で比較する
4. 意味に合う候補が先頭へ移動する
5. 候補が変わったとき、ゲーム風UIに`CHAIN +1`が現れる

正しい候補に出会うまでの迷いを減らし、「そう、それだ」と思える一瞬をつくります。AIが停止した場合はMozcの候補順に戻るため、普段の入力も止まりません。

## AIの使い方

- **モデル:** Ruri v3 310M教師モデルからRuri v3 70Mへ知識蒸留
- **推論:** Dual-Encoderで文脈ベクトルと候補ベクトルを分離し、内積で比較
- **速度設計:** CPUはINT8、GPUはFP16。入力中に文脈と候補を先読み
- **安全設計:** Mozcの候補だけを再順位付けし、最大15候補を処理。AI失敗時はMozcへ戻す
- **開発工程:** `【実際に利用した生成AIサービス名を追記】` をコード調査、実装、テスト、文章整理の支援に利用。生成物は人が確認

## つくった理由

IMEは「変換できる」だけでなく、「今の文章に合う言葉がすぐ選べる」必要があります。クラウドへ入力を送らず、生成AIに全文を任せず、既存IMEの操作感を残したまま、文脈理解だけを追加する。その制約があるからこそ、毎日の小さな入力に届くプロダクトを目指しました。

## 検証

- 実際のMozc候補を使った210例
- 日常、仕事、IT、医療、製造、数字・固有表現を含む
- 自然な表記を含めた正解率: **Mozcのみ 72.4% → AI併用 99.1%**
- この数値は検証用データの結果で、製品全体の精度保証ではありません
