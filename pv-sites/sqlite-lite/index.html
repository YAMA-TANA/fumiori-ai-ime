FREE SQLITE VIEWER ONLINE

SQLiteファイルを、インストールせずに開いて確認

SQLite LITEは、SQLite Database Browserを入れるほどではない確認作業向けの無料SQLite viewerです。.db / .sqlite / .sqlite3をブラウザで開き、テーブル・ビュー一覧、SQL結果、実行計画を確認できます。SQLite本体はWeb Worker側で動作し、DBファイルは外部サーバーへアップロードしません。

SQLite DBを開く

SQLiteのマジックヘッダーを確認してから読み込み、テーブルとビューを一覧表示します。最大256MBを安全上限にしています。

SQLを実行

SELECTなどのSQLをWorker内で実行。重いクエリでもUIを分離し、必要ならキャンセルできます。

結果をCSVへ

表形式の結果をCSV保存。表示用結果は最大5,000行、DOM描画は200行ずつに分けて大きな結果での固まり方を抑えます。

DBをローカル保存

変更後のSQLiteデータベースを再び.sqliteとして保存できます。BLOBは画面表示時に容量表記へ変換して保持量を抑えます。

SQLite LITEのよくある質問

オンラインSQLite Viewerですが、DBはアップロードされますか？

いいえ。SQLite処理はブラウザ内のWeb Workerで行います。アクセス解析はありますが、開いたDBファイル本体を解析サーバーへ送信する処理はありません。

複数のSQL文をまとめて実行できますか？

安全性と状態管理を単純にするため、現在は一度に1つのSQL文を実行する設計です。

SQLite Browserの完全な代替ですか？

いいえ。軽い確認・クエリ・CSV/DB保存に絞ったツールです。高度なDB設計や大規模編集はデスクトップDBツールの方が適しています。
