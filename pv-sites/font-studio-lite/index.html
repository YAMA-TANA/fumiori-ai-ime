GLYPH SAMPLE

Portable specimen.

Uploaded fonts remain local. PNG is rasterized in-browser; SVG export embeds the uploaded font data itself so the specimen can retain the same typeface on another machine. System-font SVGs remain dependent on the viewing system.

FREE FONT PREVIEW ONLINE

フォントをインストールせず、文章で確認するFont Tester

FONT STUDIO LITEは、TTF・OTF・WOFF・WOFF2をローカルで読み込む無料のfont previewツールです。フォント名だけを見るのではなく、実際の文章、複数行、字間、行間、ウェイト、配色まで一つのspecimenとして確認できます。

TTF / OTF Viewer

ローカルフォントをFontFace APIで一時読み込み。OSへインストールせずに見た目を確認できます。

日本語・英語を文章で確認

好きな文章を最大5,000文字まで入力し、字間・行間・サイズ・ウェイトを変更して実際の組版に近い状態で比較できます。

PNGへ書き出し

見本を1x / 2x / 3xのPNGとして保存。SNSやデザインレビュー用の画像をブラウザ内で作れます。

フォント埋め込みSVG

アップロードフォントならデータをSVGへ埋め込み、別環境でも同じ書体を保ちやすい自己完結specimenを生成します。

Font Previewのよくある質問

フォントをPCへインストールする必要がありますか？

ありません。アップロードしたフォントはこのページ内だけで読み込まれます。

WOFF2も確認できますか？

はい。ブラウザがそのフォント形式を読み込める場合、WOFF2 / WOFF / TTF / OTFに対応します。

商用利用できるフォントか判定できますか？

ライセンス判定機能ではありません。利用条件は配布元のライセンスやEULAを必ず確認してください。
